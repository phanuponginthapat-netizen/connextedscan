# FaceGate Scanner — ไฟล์ APK สำหรับแท็บเล็ต

แอป Android ตัวนี้เป็นตัวสแกนใบหน้าสำหรับแท็บเล็ต/มือถือเครื่องเก่า ใช้โมเดลใบหน้าแบบเบา
(ทำงานผ่านหน้า `/tablet` ของระบบ) เปิดเต็มจอ มีไอคอนแอป และขอสิทธิ์กล้องเหมือนแอปทั่วไป

## สเปคขั้นต่ำของแท็บเล็ต

- Android 8.0 ขึ้นไป
- แรม 3 GB ขึ้นไป (4 GB ลื่นกว่า)
- กล้องหน้า 2 ล้านพิกเซลขึ้นไป
- ต่ออินเทอร์เน็ตตลอดเวลา (Wi‑Fi แนะนำ)
- พื้นที่ว่างประมาณ 200 MB

## สร้าง APK แบบอัตโนมัติ (แนะนำ)

1. เชื่อมโปรเจกต์กับ GitHub
2. ไปที่แท็บ **Actions → Build Tablet APK → Run workflow**
3. ใส่ URL ของเว็บระบบ (ถ้าไม่ใส่จะใช้ค่าเริ่มต้น) แล้วกด Run
4. เมื่อเสร็จ ดาวน์โหลดไฟล์จาก **Artifacts → FaceGate-Scanner-apk**

## สร้าง APK บนเครื่องตัวเอง

ต้องมี Node.js 20+, JDK 17 และ Android SDK (ตั้งค่า `ANDROID_HOME`)

```bash
bash mobile/apk/build-apk.sh https://connextedscan.lovable.app
```

ได้ไฟล์ `mobile/apk/FaceGate-Scanner.apk`

## ให้ดาวน์โหลดจากหน้าเว็บ

วางไฟล์ APK ไว้ที่ `public/downloads/FaceGate-Scanner.apk`
หน้าดาวน์โหลดจะมีปุ่ม “ดาวน์โหลดแอปสำหรับแท็บเล็ต (APK)” ให้ทันที
หรือถ้าเก็บไฟล์ไว้ที่อื่น (เช่น GitHub Releases) ให้ใส่ลิงก์ที่
หลังบ้าน → ตั้งค่า → เนื้อหา → “ลิงก์ไฟล์ APK สำหรับแท็บเล็ต”

## ติดตั้งบนแท็บเล็ต

1. เปิดหน้าดาวน์โหลดของระบบบนแท็บเล็ต แล้วกดดาวน์โหลด APK
2. อนุญาต “ติดตั้งแอปจากแหล่งนี้” เมื่อระบบถาม
3. เปิดแอป → อนุญาตกล้อง → ใส่รหัสเครื่องจากหลังบ้าน → เลือกเข้า/ออก/อัตโนมัติ

หมายเหตุ: โหมดแท็บเล็ตไม่ควบคุมประตู micro:bit และช้ากว่าเครื่องที่ติดตั้ง FaceGate บน PC
