# เพิ่มป้ายประชาสัมพันธ์และสถิติหน้าพัก

## สิ่งที่จะทำ
- เพิ่มส่วนจัดการสื่อประชาสัมพันธ์ในหลังบ้าน อัปโหลดรูปภาพและวิดีโอได้หลายไฟล์ เปิด/ปิด ลบ และจัดลำดับการแสดงได้
- เก็บสื่อออนไลน์ในพื้นที่ไฟล์ส่วนตัว และส่งลิงก์ชั่วคราวที่ปลอดภัยให้หน้าตู้สแกน
- ทำความสามารถเดียวกันในชุดติดตั้งแบบใช้งานภายในเครื่อง
- ออกแบบหน้าพักเป็นป้าย Broadcast: สื่อเด่นเต็มพื้นที่ สลับอัตโนมัติ พร้อมชื่อโรงเรียน วันที่ และสถิติที่อ่านได้ในระยะไกล
- เปลี่ยนสถิติเป็น นักเรียนทั้งหมด/มาวันนี้/ขาด และบุคลากรทั้งหมด/มาวันนี้/ขาด โดยไม่แสดง “ยังไม่มา”
- ขยายข้อความ “กรุณายืนให้ใบหน้าตรงกับกรอบใบหน้าบนหน้าจอ” เฉพาะจอแนวตั้ง และคงให้อยู่บรรทัดเดียวในกรอบสีน้ำเงิน
- ตรวจทั้งจอแนวตั้งและแนวนอน รวมถึงการสลับรูป วิดีโอ และการกลับมาสแกนทันทีเมื่อพบใบหน้า

## รายละเอียดทางเทคนิค
- เพิ่มตารางรายการสื่อพร้อมสิทธิ์เข้าถึงที่จำกัด และ bucket ส่วนตัวสำหรับไฟล์ประชาสัมพันธ์
- เพิ่ม API สำหรับรายการสื่อที่เปิดใช้งานและ URL ชั่วคราว
- รูปภาพเปลี่ยนตามช่วงเวลา ส่วนวิดีโอเล่นจนจบแล้วจึงไปไฟล์ถัดไป โดยย้อนวนทั้งชุด
- หน้าพักยังไม่หยุดกล้องหรือวงจรตรวจจับใบหน้า
