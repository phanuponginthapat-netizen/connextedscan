# FaceGate Standalone — ตัวติดตั้งจบในเครื่อง ไม่ต้องพึ่งระบบกลาง

เป้าหมาย: มีไฟล์ดาวน์โหลดอีกแบบหนึ่ง ที่ติดตั้งลงคอมเครื่องเดียวแล้วใช้ได้ครบ
ทั้งตู้สแกนและหน้าหลังบ้าน โดยไม่ต้องต่ออินเทอร์เน็ต และแต่ละโรงเรียนมีข้อมูลของตัวเอง
แยกกันสมบูรณ์

## สิ่งที่ผู้ใช้จะได้

- ไฟล์ `FaceGate-Standalone-windows-x64.zip` (และ Linux) ดาวน์โหลดจากหน้าดาวน์โหลด
- ติดตั้งครั้งเดียว เปิดโปรแกรม → ใช้ได้ทันที ไม่ต้องใส่รหัสเครื่อง ไม่ต้องมีเน็ต
- หน้าหลังบ้านในเครื่อง (กด F9 หรือเปิด `http://127.0.0.1:8899/admin`):
  ลงทะเบียนใบหน้า, รายชื่อคน, ประวัติการสแกน, รายงาน, ตั้งค่าเวลาเข้า–ออก,
  ประตูอัจฉริยะ, ประหยัดพลังงาน, ใบรับรองเวลาเรียน
- ข้อมูลทั้งหมดเก็บเป็นไฟล์เดียวในเครื่อง สำรอง/ย้ายเครื่องได้ด้วยการคัดลอกไฟล์
- นำเข้ารายชื่อจาก Excel/CSV และส่งออกรายงานเป็นไฟล์ได้เหมือนเดิม

## สิ่งที่จะไม่มีในโหมดนี้ (ตรงไปตรงมา)

- ดูข้อมูลข้ามโรงเรียนรวมกันไม่ได้ (ตามที่เลือก: แยกคนละระบบ)
- แจ้งเตือนอีเมล/LINE และปลุกเครื่องจากนอกโรงเรียน ต้องมีเน็ตจึงทำงาน
  (ถ้าไม่มีเน็ต ระบบจะเก็บคิวไว้และข้ามไป ไม่ค้าง)
- ระบบกลางบนเว็บยังอยู่ตามเดิม ใครจะใช้แบบเดิมก็ยังใช้ได้

## แนวทางทางเทคนิค

โหมดนี้ไม่สร้างโปรแกรมใหม่ทั้งหมด แต่ยกส่วนที่จำเป็นลงมาไว้ใน agent เดิม
ที่มี FastAPI + Python ฝังมาในไฟล์ครบชุดอยู่แล้ว

1. **ฐานข้อมูลในเครื่อง** — `agent/localdb.py` ใช้ SQLite (มีใน Python ไม่ต้องลงเพิ่ม)
   สร้างตารางให้ตรงกับระบบกลาง: people, face_embeddings, attendance_logs,
   settings, devices, door_commands, device_commands, visitor_logs,
   security_alerts, audit_logs, site_content
   เก็บที่ `%APPDATA%/facegate/data/facegate.db` (Linux: `~/.local/share/facegate/data/`)
   รูปใบหน้าเก็บเป็นไฟล์ในโฟลเดอร์ `data/snapshots/`

2. **ชั้น API ในเครื่อง** — `agent/local_api.py` ให้ endpoint ชุดเดียวกับที่ตู้สแกน
   และหน้าหลังบ้านเรียกอยู่ตอนนี้ (`/api/public/kiosk/*`, `/api/local/admin/*`)
   แต่ตอบจาก SQLite แทน ทำให้โค้ดหน้าเว็บใช้ซ้ำได้ทั้งหมด

3. **หน้าเว็บทำงานสองโหมด** — เพิ่ม `src/lib/api-base.ts`:
   ถ้าเปิดผ่าน `127.0.0.1:8899` ให้ยิงไปที่ API ในเครื่อง ถ้าไม่ใช่ก็ยิงไปคลาวด์เดิม
   หน้าเดิม (kiosk, admin ทั้งหมด) เปลี่ยนมาเรียกผ่านตัวนี้ ไม่ต้องเขียนหน้าใหม่

4. **ตัวจัดการผู้ใช้แบบเครื่องเดียว** — `agent/local_auth.py`
   ผู้ดูแล 1 บัญชี (ตั้งรหัสตอนเปิดโปรแกรมครั้งแรก) เก็บรหัสแบบแฮช
   ออก session token ในเครื่อง ไม่ใช้ระบบล็อกอินคลาวด์

5. **สร้างหน้าเว็บเป็นไฟล์นิ่ง** — เพิ่มสคริปต์ที่ build หน้าเว็บ (โหมด SPA)
   แล้ววางลงใน `resources/webui` ให้ FastAPI เสิร์ฟตรง ๆ ตัว Electron
   เปิด `http://127.0.0.1:8899/kiosk` แทนการเปิดคลาวด์

6. **ตัวสร้างไฟล์ติดตั้ง** — `bundle/build-standalone-windows.ps1` และ
   `bundle/build-standalone-linux.sh` (ต่อยอดสคริปต์เดิม + เพิ่ม webui)
   และเพิ่มงานใหม่ใน `.github/workflows/facegate-bundle.yml` ปล่อยขึ้น GitHub Release

7. **โหมดในโปรแกรม** — `electron/main.cjs` เพิ่ม `mode: "standalone" | "cloud"`
   โหมด standalone ข้ามการเช็ครหัสเครื่องและการอัปเดตจากคลาวด์

8. **สำรอง/กู้คืน** — หน้าหลังบ้านในเครื่องมีปุ่มสำรองเป็นไฟล์เดียว
   และปุ่มกู้คืน (ใช้ย้ายไปเครื่องใหม่หรือย้ายไปโรงเรียนอื่น)

## ลำดับการทำงาน

1. ฐานข้อมูล + API ในเครื่อง + บัญชีผู้ดูแล (แกนหลัก)
2. ปรับหน้าเว็บให้เรียก API ตามโหมด + build เป็นไฟล์นิ่ง
3. ตัวสร้างไฟล์ติดตั้ง standalone + ปุ่มดาวน์โหลดในหน้าดาวน์โหลด
4. สำรอง/กู้คืน + คู่มือติดตั้งฉบับสั้น

งานนี้ค่อนข้างใหญ่ ผมจะทำเป็นรอบ ๆ ตามลำดับนี้ และแจ้งผลทุกรอบ
