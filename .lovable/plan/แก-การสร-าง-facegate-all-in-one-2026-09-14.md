# แก้การสร้าง FaceGate all-in-one

## สิ่งที่จะเปลี่ยน
- เพิ่มหมายเลขเวอร์ชัน `1.4.0` และชื่อผู้จัดทำ `ConnextED` ในข้อมูลโปรแกรมที่ตัวแพ็ก Electron ต้องอ่าน
- คงคำสั่งสร้าง Windows และ Linux เดิมไว้ เพราะบันทึกยืนยันว่าการดาวน์โหลด Python ไลบรารี และโมเดลผ่านครบแล้ว
- ตรวจรูปแบบไฟล์และคำสั่งแพ็กเบื้องต้นก่อนให้รัน GitHub Actions ใหม่

## ผลลัพธ์
ตัวสร้างจะผ่านข้อผิดพลาด `Could not locate a package.json ... with fields: version, author` ทั้ง Windows และ Linux และเดินหน้าสู่ขั้นบีบอัดไฟล์ต่อได้
