# สแกนใบหน้าจบบนเว็บ (ไม่ต้องติดตั้งโปรแกรม)

เพิ่ม "โหมดเว็บ" ให้ตู้สแกนทำงานได้ทันทีจากหน้าเว็บ โดยไม่ต้องลงโปรแกรมบนเครื่อง
ถ้าเครื่องไหนติดตั้งโปรแกรมตรวจใบหน้าไว้แล้ว ระบบจะสลับไปใช้ตัวนั้นให้อัตโนมัติ (แม่นกว่า)

## ผู้ใช้จะเห็นอะไร

- หน้าสแกนเปิดกล้องแล้วทำงานได้เลย ไม่มีแถบแดง "ยังไม่ได้เชื่อมต่อโปรแกรม" อีกต่อไป
- มีป้ายบอกว่ากำลังใช้ "โหมดเว็บ" หรือ "โหมดโปรแกรมบนเครื่อง"
- ยังคงกรอบวงรีคนเดียว, ปฏิเสธเมื่อเจอหลายใบหน้า, ขานชื่อภาษาไทย, นับถอยหลังคนถัดไป, กันสแกนซ้ำ เหมือนเดิมทุกอย่าง
- หน้าลงทะเบียนใบหน้าในหลังบ้าน จะเตรียมข้อมูลใบหน้าสำหรับโหมดเว็บให้เองตอนอัปโหลด/ถ่ายรูป
- ในหน้าตั้งค่า เพิ่มตัวเลือกความเข้มงวดของโหมดเว็บ และปุ่ม "เตรียมข้อมูลใบหน้าโหมดเว็บย้อนหลัง" สำหรับคนที่ลงทะเบียนไว้ก่อนหน้านี้

## การตัดสินอยู่ที่เซิร์ฟเวอร์

หน้าเว็บทำหน้าที่แค่จับภาพและวัดค่าใบหน้า แล้วส่งค่านั้นขึ้นระบบ
การเทียบว่าเป็นใคร ผ่านหรือไม่ผ่าน บันทึกเข้า-ออก กันสแกนซ้ำ ทั้งหมดตัดสินบนเซิร์ฟเวอร์เหมือนเดิม
(ทำแบบนี้เพราะระบบคลาวด์รันโมเดลใบหน้าเองไม่ได้ แต่ข้อมูลใบหน้าทั้งหมดและอำนาจตัดสินยังอยู่ฝั่งระบบ)

## รายละเอียดทางเทคนิค

1. **โมเดลในเบราว์เซอร์**: ใช้ `@vladmandic/face-api` (TF.js, WASM/WebGL) โหลด tinyFaceDetector + faceLandmark68 + faceRecognitionNet ได้ descriptor 128 มิติ + landmarks
   - ไฟล์โมเดลวางที่ `public/models/` เพื่อให้ทำงานได้แม้เน็ตช้า
   - หุ้มด้วย `<ClientOnly>` / dynamic import ใน `useEffect` เท่านั้น

2. **ฐานข้อมูล** (migration ใหม่)
   - `student_faces`: เพิ่ม `web_embedding double precision[]`, `web_geometry jsonb`
   - `settings`: เพิ่ม `web_match_threshold` (ค่าเริ่ม 0.42 cosine distance) และ `allow_web_scan boolean default true`
   - grants ตามเดิมสำหรับตารางที่แก้ (ไม่มีตารางใหม่)

3. **API ใหม่** `src/routes/api/public/kiosk/web-scan.ts`
   - รับ `{ descriptor: number[128], geometry, snapshot }` ไม่ต้องใช้ device key ก็ได้ แต่ถ้ามีจะบันทึกชื่อเครื่อง
   - เทียบกับ `web_embedding` ทุกคนที่ active หา best match + margin กับอันดับสอง
   - ถ้าผ่าน threshold → ใช้ตรรกะเดิมของ `attendance.ts` (ทิศทาง เข้า/ออก, cooldown, มาสาย, snapshot, เสียง) โดยแยกตรรกะร่วมไปไว้ที่ `src/lib/kiosk-attendance.server.ts` เพื่อไม่ให้โค้ดซ้ำ
   - ถ้าไม่ผ่าน → `denied` พร้อมข้อความ/เสียงปฏิเสธ

4. **เตรียมใบหน้าโหมดเว็บ** `src/lib/web-faces.functions.ts`
   - server fn ดึงรายการใบหน้าที่ยังไม่มี `web_embedding` พร้อม signed URL
   - server fn บันทึก descriptor ที่คำนวณจากเบราว์เซอร์กลับเข้า `student_faces`
   - เรียกใช้ตอนอัปโหลดรูปใน `PersonDetail.tsx` และจากปุ่มประมวลผลย้อนหลังในหน้าตั้งค่า

5. **หน้าสแกน** `src/routes/kiosk.tsx`
   - ตรวจ `/health` ของโปรแกรมบนเครื่องก่อน: เจอ → ใช้เส้นทางเดิม, ไม่เจอ → เข้าโหมดเว็บอัตโนมัติ
   - โหมดเว็บ: ตรวจใบหน้าในเฟรม → 0 หน้า = "ไม่พบใบหน้า", >1 = "กรุณาเข้ามาคนเดียว", 1 หน้า = ส่งขึ้น `web-scan`
   - ปรับจังหวะสแกนให้เหมาะกับเครื่องช้า (ตรวจใบหน้าเบา ๆ ต่อเนื่อง แล้วค่อยคำนวณ descriptor เมื่อพบใบหน้านิ่ง)

## ข้อจำกัดที่ต้องบอกผู้ใช้

- โหมดเว็บแม่นน้อยกว่าโปรแกรม ArcFace เล็กน้อย และบนเครื่อง Intel Atom จะใช้เวลาราว 1-3 วินาทีต่อครั้ง
- ต้องเปิดหน้าเว็บผ่าน HTTPS จึงจะใช้กล้องได้
