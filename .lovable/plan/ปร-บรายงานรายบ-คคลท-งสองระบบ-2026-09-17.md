# ปรับรายงานรายบุคคลทั้งสองระบบ

## เป้าหมาย
แยกรายงานสองประเภทให้ชัดเจน:
- **รายงานรายบุคคล** — ติดตามการมา สาย ขาด และอัตราการมา ของนักเรียนหรือบุคลากรแต่ละคนในช่วงวันที่เลือก
- **รายงานการมาโรงเรียน** — สรุปภาพรวมรายชั้นและรายชื่อนักเรียนที่ขาดในแต่ละวัน คงไว้เป็นเมนูแยก

## สิ่งที่จะปรับ
1. เปลี่ยนชื่อเมนูและหัวหน้ารายงานเดิมจาก “รายงาน/รายงานรายเดือน” เป็น “รายงานรายบุคคล” ทั้งระบบออนไลน์และ Standalone รวมถึงชื่อไฟล์ CSV และข้อความใน CMS
2. เพิ่มตัวกรองในรายงานรายบุคคล: ช่วงวันที่, นักเรียน/บุคลากร, ชั้นหรือฝ่าย, และค้นหารหัสหรือชื่อ
3. เพิ่มตัวเลขสรุปที่ใช้ติดตามได้ทันที: จำนวนคน, วันเรียน/วันทำงาน, อัตรามาเฉลี่ย, มาสายรวม และขาดรวม
4. จัดตารางรายบุคคลให้เรียงลำดับได้ และแสดงรหัส ชื่อ ประเภท ชั้น/ฝ่าย มา สาย ขาด และอัตรามา พร้อมสถานะที่อ่านง่าย
5. ปรับการคำนวณให้ใช้วันทำงานตามการตั้งค่าของโรงเรียน ไม่ใช้เพียงวันที่เคยมีคนสแกน เพื่อให้ยอดขาดแม่นยำขึ้น
6. รองรับดาวน์โหลด CSV และพิมพ์ โดยข้อมูลตรงกับตัวกรองที่เลือก
7. คง “รายงานการมาโรงเรียน” และรายชื่อผู้ขาดแยกเป็นเมนูเดิมอย่างชัดเจน

## รายละเอียดทางเทคนิค
- ออนไลน์: ปรับหน้ารายงานปัจจุบันและค่าเมนู CMS โดยอ่าน `work_days` และ `block_non_work_days` จากการตั้งค่า
- Standalone: ขยาย API รายงานให้ส่งข้อมูลรายบุคคลครบถ้วน และปรับหน้ารายงานให้มีตัวกรอง/สรุป/CSV แบบเดียวกับออนไลน์
- รูปแบบวันที่ใช้ พ.ศ. และเวลา 24 ชั่วโมงตามมาตรฐานเดิมของระบบ
- ตรวจการคำนวณ, Python syntax, หน้าเว็บ และสถานะ build หลังแก้ไข
