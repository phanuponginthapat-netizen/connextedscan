# ให้ FaceGate เก็บข้อมูลใบหน้าไว้ในเครื่อง

ทำได้ครับ และช่วยได้จริงทั้งความไวและความแม่นยำ แนวทางคือให้โปรแกรม FaceGate ดาวน์โหลดรูปและค่าที่วัดได้ของทุกคนมาเก็บไว้ในเครื่องตู้ แล้วใช้ข้อมูลในเครื่องเป็นหลักตอนสแกน

## สิ่งที่จะได้
- เปิดโปรแกรมปุ๊บพร้อมสแกนทันที ไม่ต้องรอโหลดข้อมูลจากอินเทอร์เน็ต
- เน็ตช้าหรือเน็ตหลุดชั่วคราวก็ยังสแกนและจดจำคนได้ (บันทึกเวลาจะส่งขึ้นระบบให้เมื่อเน็ตกลับมา)
- แม่นขึ้น เพราะเครื่องเก็บรูปไว้ครบ จึงคำนวณค่าใบหน้าใหม่ได้เองเมื่อมีรุ่นใหม่ โดยไม่ต้องโหลดรูปซ้ำ
- ประหยัดอินเทอร์เน็ต เพราะโหลดเฉพาะคนที่เพิ่ม/แก้ไขใหม่เท่านั้น

## สิ่งที่จะทำ
1. **คลังข้อมูลในเครื่อง** เพิ่มโฟลเดอร์เก็บข้อมูลของ FaceGate (รูปใบหน้า ค่าที่วัดได้ รายชื่อบุคคล และการตั้งค่า) เก็บเป็นไฟล์ในเครื่องตู้
2. **เปิดโปรแกรมแล้วใช้ข้อมูลเก่าได้ทันที** โหลดจากไฟล์ในเครื่องก่อน แล้วค่อยอัปเดตกับระบบเบื้องหลัง
3. **ซิงก์เฉพาะส่วนที่เปลี่ยน** ระบบส่งเวลาอัปเดตล่าสุดของแต่ละคนมาด้วย เครื่องจะโหลดเฉพาะรายการใหม่หรือที่แก้ไข และลบรายการที่ถูกลบออก
4. **เก็บรูปต้นฉบับไว้ในเครื่อง** เมื่อโหลดรูปมาคำนวณค่าใบหน้าแล้ว เก็บไฟล์รูปไว้ เพื่อคำนวณใหม่ได้ทุกเมื่อโดยไม่ต้องดึงจากระบบอีก
5. **ทนเน็ตหลุด** ถ้าส่งผลการสแกนขึ้นระบบไม่สำเร็จ ให้พักไว้ในเครื่องแล้วส่งซ้ำอัตโนมัติเมื่อเชื่อมต่อได้
6. **แสดงสถานะ** หน้าสแกนบอกจำนวนใบหน้าที่เก็บไว้ในเครื่อง เวลาซิงก์ล่าสุด และจำนวนรายการที่รอส่ง

## รายละเอียดทางเทคนิค
- ที่เก็บ: `%LOCALAPPDATA%/FaceGate/cache/` (Windows) — `faces.json` (embeddings + geometry + updated_at), `students.json`, `settings.json`, `images/<face_id>.jpg`, `outbox.jsonl`
- `agent/agent.py`: โหลด cache ตอนบูตก่อน `sync_loop`, เขียน cache แบบ atomic (`.tmp` + `os.replace`) หลังซิงก์สำเร็จ, ตัด image ที่ face_id หายไปแล้ว
- `src/routes/api/public/kiosk/sync.ts`: เพิ่ม `updated_at` ในรายการใบหน้า + รับ `known: { [face_id]: updated_at }` จาก agent แล้วส่งกลับเฉพาะ `changed` และ `removed` (ถ้าไม่ส่ง `known` มา จะทำงานแบบเดิมทั้งหมด เพื่อให้เครื่องรุ่นเก่ายังใช้ได้)
- Outbox: attendance ที่ส่งไม่สำเร็จเขียนต่อท้าย `outbox.jsonl` และมี worker thread ส่งซ้ำทุก 30 วินาที
- `/health` ของ agent เพิ่ม `cached_images`, `pending_uploads`, `last_sync` ให้หน้าสแกนแสดงผล
