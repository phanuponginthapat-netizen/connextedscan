FaceGate — รุ่นจบในเครื่อง (Standalone)
=======================================

ไฟล์ชุดนี้ทำงานได้ครบในคอมพิวเตอร์เครื่องเดียว ไม่ต้องต่ออินเทอร์เน็ต
และไม่ต้องใส่รหัสเครื่องจากระบบกลาง เหมาะกับการนำไปใช้แยกในแต่ละโรงเรียน

วิธีติดตั้ง
-----------
Windows : ดับเบิลคลิก "ติดตั้ง-FaceGate.bat" แล้วเปิดโปรแกรม FaceGate
Linux   : bash install.sh   แล้วเปิดด้วยคำสั่ง facegate

ครั้งแรกที่ใช้
--------------
1. เปิดโปรแกรม จะเข้าหน้าตู้สแกนทันที
2. กด F9 (หรือกดปุ่ม "หลังบ้าน" มุมขวาบน) เพื่อเข้าหน้าหลังบ้านในเครื่อง
3. ตั้งรหัสผู้ดูแลของเครื่องนี้ (อย่างน้อย 6 ตัวอักษร)
4. ใส่ชื่อโรงเรียนและเวลาสแกนเข้า–ออก ที่หัวข้อ "ตั้งค่าระบบ"
5. เพิ่มรายชื่อคนที่ "รายชื่อคน" แล้วลงทะเบียนใบหน้าที่ "ลงทะเบียนใบหน้า"

ข้อมูลของโรงเรียนเก็บไว้ที่ไหน
------------------------------
Windows : C:\Users\<ชื่อผู้ใช้>\AppData\Roaming\FaceGate\data
Linux   : ~/.config/FaceGate/data

สำรองข้อมูลได้จากหลังบ้าน → สำรองข้อมูล (ได้ไฟล์ zip ไฟล์เดียว)
ย้ายไปเครื่องใหม่: ติดตั้งโปรแกรม แล้วกู้คืนจากไฟล์สำรองนั้น

สิ่งที่รุ่นนี้ไม่มี
-------------------
- ดูข้อมูลรวมหลายโรงเรียนในที่เดียว (แต่ละเครื่องเป็นระบบของตัวเอง)
- แจ้งเตือนอีเมล/LINE และสั่งงานจากนอกโรงเรียน (ต้องมีอินเทอร์เน็ต)

อุปกรณ์ประตูอัจฉริยะ (micro:bit) ใช้ได้ตามปกติ ต่อ USB เข้าเครื่องนี้
และจ่ายไฟ 5V แยกให้เซอร์โว โดยต่อ GND ร่วมกับ micro:bit
